About Me

I am a DevOps Engineer focused on building scalable, secure, and automated cloud infrastructure. My work revolves around improving deployment speed, system reliability, and operational efficiency through modern DevOps practices.

I have hands-on experience working with major cloud providers including AWS, Google Cloud Platform (GCP), and Microsoft Azure. I have deployed production-scale applications across AWS, Azure, and GCP, with a strong focus on infrastructure design, CI/CD pipeline automation, containerization, and cloud-native deployments.

I have worked with version control and collaboration platforms including GitHub and Bitbucket, and I build containerized environments using Docker and Docker Compose. I am also comfortable working across multiple Linux distributions such as Ubuntu, Debian, AlmaLinux, and CentOS for server administration, deployments, and troubleshooting.

My AWS experience covers services such as EC2, RDS, ECS, ECR, SES, Elastic Beanstalk, Amplify, Lightsail, S3, CloudFront, and VPC configuration. I also work with infrastructure as code using CloudFormation and Terraform, and I support backend systems and databases including PostgreSQL, Node.js, and .NET applications.

My focus is always on automation, reliability, security, and scalability. I enjoy designing clean cloud architectures, improving delivery workflows, strengthening observability, and building deployment pipelines that help teams ship software faster and more confidently.
